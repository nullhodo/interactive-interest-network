# Interactive Interest Network

私の興味や関心を視覚的に表現するインタラクティブなネットワーク可視化プロジェクト。
インタラクティブ性やゲーム性を楽しみながら私について知ることができるかも。

## プロジェクト概要

- **目的**: 趣味や関心事をノードとリンクによるネットワーク図として視覚化し、インタラクティブに探索できるようにします。
- **可視化エンジン**: D3.js (d3-force) を使用した力学シミュレーションにより、ノードが互いに反発・結合しながら動的に配置されます。
- **アニメーション**: テーマカラーに応じた石のような質感の立体的なグラデーションと、未展開ノードが鼓動するように光るリフレクティブパルスアニメーションを採用しています。
  - ノードは角丸長方形ではなく曲率が連続なsuperellipseを使用。
- **操作**:
  - **展開/収納**: superellipseのノードをクリックすることで子カテゴリを展開、または収納できます。
  - **外部リンク**: URLが登録されているノードをクリックすると、関連するウェブサイトや動画を新規タブで開きます。
  - **移動/ズーム**: 空白部分をドラッグするか、キーボード（WASD / 矢印キー）でフィールドを移動できます。また、マウスホイールでズームイン・アウトが可能です。

## 技術スタック

- **ビルドツール**: Vite
- **パッケージマネージャー**: pnpm
- **フロントエンド言語**: TypeScript
- **UIライブラリ**: React (状態管理のために使用)
- **可視化ライブラリ**: D3.js
- **スタイリング**: Vanilla CSS
- **コードフォーマッタ**: Prettier (データファイル専用)

## ディレクトリ構成

- `index.html`: アプリケーションのエントリーポイントとなるHTML
- `.prettierrc`: フォーマッタの設定ファイル（データファイルのキーごとの改行ルールをオーバーライド）
- `.prettierignore`: `interestData.ts` 以外のファイルを Prettier の自動フォーマットから除外する設定
- `src/`
  - `main.tsx`: Reactアプリのレンダリングを行うエントリーポイント
  - `App.tsx`: メインコンポーネント
  - `types.ts`: TypeScriptの型定義（関心事ノード、D3シミュレーション用ノードなど）
  - `components/`
    - `WordCloud.tsx`: D3.jsのシミュレーションと描画、およびUIイベントを処理するコンポーネント
  - `data/`
    - `interestData.ts`: 興味や関心の木構造データ本体（追加・編集はここで行います）
    - `initialData.ts`: 読み込んだデータへの動的なテーマカラー設定および初期化ロジック
  - `styles/`
    - `index.css`: アプリケーションのスタイルシート（フォント読み込み、レイアウト、アニメーション定義を含む）
