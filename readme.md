# Interactive Interest Network

私の興味や関心を視覚的に表現するインタラクティブなネットワーク可視化プロジェクト。
インタラクティブ性やゲーム性を楽しみながら私について知ることができるかも。

## プロジェクト概要

- **目的**
  趣味や関心事をノードとリンクによるネットワーク図として視覚化し、インタラクティブに探索できるようにします。
- **可視化エンジン**
  D3.js (`d3-force`) を使用した力学シミュレーションにより、ノードが互いに反発・結合しながら動的に配置されます。
- **アニメーションとビジュアル**
  - **superellipse ノード**
    角丸長方形の代わりに、曲率が連続で滑らかな superellipse をパラメトリック方程式を用いて動的に描画しています。
  - **3層構造の質感表現**
    ドロップシャドウ用の影レイヤー、テーマカラーまたは石調のメインレイヤー、そして `clipPath` で superellipse 内部にクリッピングされた反射光レイヤーの3層で立体感を表現。
  - **滑らかな出入りトランジション**
    - **展開**
      親ノードの現在位置から、周囲（半径20〜40px）にランダムに散らばりながらシュッと飛び出し、スケールアップして出現します。
    - **収納**
      子ノードがスケールダウンしつつ、親ノードの背後のレイヤーへリアルタイムの親の座標を追いかけながらスムーズに吸い込まれて消去されます。
    - **リンク追従**
      展開・収納に合わせて、接続しているリンクもノードの移動にぴったり追従して伸縮しながらフェードイン・アウトします。
  - **鼓動する光の演出**
    未展開で子ノードを持つノードは、鼓動するように波打つリフレクティブパルスアニメーションと、数秒おきに斜めに光が走るスイープアニメーションが機能します。
- **物理シミュレーションの安定化**
  - **一時的な親固定**
    展開・収納をクリックした際、アニメーション中の350ms間だけ親ノードの座標を強制ピン留め (`fx`, `fy`) して不要なズレや画面のブレを排除。
  - **斥力の動的 alpha 制御**
    展開・収納によりノード数が変化した際、急な斥力変化で周囲のノードが弾け飛ばないよう、再始動時の `alpha` を `0.08` に抑制して穏やかに再配置します。
- **操作**
  - **展開/収納**
    ノードをクリックすることで子カテゴリを展開、または収納できます。
  - **外部リンク**
    URLが登録されているノードをクリックすると、関連するウェブサイトや動画を新規タブで開きます。
  - **移動/ズーム**
    空白部分をドラッグするか、キーボード（WASD / 矢印キー）でフィールドを移動できます。また、マウスホイールでズームイン・アウトが可能です。

## 技術スタック

- **ビルドツール**
  Vite
- **パッケージマネージャー**
  pnpm
- **フロントエンド言語**
  TypeScript
- **UIライブラリ**
  React (状態管理のために使用)
- **可視化ライブラリ**
  D3.js
- **スタイリング**
  Vanilla CSS
- **コードフォーマッタ**
  Prettier (データファイル専用)

## ディレクトリ構成

```text
├── index.html            # アプリケーションのエントリーポイントとなるHTML
├── .prettierrc           # データファイル専用のフォーマットルール設定ファイル
├── .prettierignore       # interestData.ts 以外のファイルを自動フォーマットから除外
├── package.json          # 依存関係、ビルドスクリプトの定義
├── src/
│   ├── main.tsx          # Reactアプリのレンダリングを行うエントリーポイント
│   ├── App.tsx           # メインのレイアウトコンポーネント
│   ├── types.ts          # TypeScript型定義（InterestNode、SimulationNodeなど）
│   ├── components/
│   │   └── WordCloud.tsx # D3.jsシミュレーションの初期化、データ結合(Enter/Update/Exit)、描画、UIイベントハンドラ
│   ├── data/
│   │   ├── interestData.ts # 興味や関心の木構造データ本体（追加・編集はここで行います）
│   │   └── initialData.ts  # データ前処理（BFSによるルートカラー・深さ・主要親の伝播）
│   └── styles/
│       └── index.css       # アプリ全体のスタイルシート（反射光キーフレーム、鼓動アニメーション、asciiアート仕様図を含む）
```

## コマンド

| コマンド | 説明 |
| :--- | :--- |
| `pnpm install` | 依存関係のインストール |
| `pnpm dev` | 開発サーバーの起動 |
| `pnpm format` | `interestData.ts` のPrettierによる自動整形 |
| `pnpm build` | 本番用ビルドの生成 |
